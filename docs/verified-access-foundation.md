# PataSpace Verified Access Foundation

This module extends the accepted Master Prompts 1–15B and preserves the platform-wide Customer Access Control Standard.

## Objective

Verified Access allows customers to temporarily access multiple qualifying matching properties through one purchase. It exists for customers who want to compare several matching properties before deciding which one to contact or visit.

Verified Access complements Unlock This Listing and never replaces it.

## Coverage

Verified Access applies to Houses, Shops, Offices and Event Halls. No property category may bypass the workflow.

## Pricing

Verified Access uses the centrally managed Founder-approved pricing tables established in the Unlock This Listing Foundation. Customers never manually enter an amount, and Property Owners, Property Managers and Leasing Agents cannot modify pricing.

## Eligibility

Verified Access is recommended only according to Founder-approved recommendation logic:

- If one or two suitable properties are available, prioritise Unlock This Listing.
- If several suitable properties are available within the approved batch, recommend Verified Access while continuing to offer individual unlocks.

Customers always retain both purchasing options.

## Access duration

Verified Access grants premium access for **72 Hours**. The access period begins immediately after successful payment confirmation.

## Access scope

Verified Access applies only to the properties covered by the approved recommendation. It never unlocks unrelated properties outside the applicable search results.

## Premium information

While Verified Access is active, customers may access all uploaded property photos, Property Owner phone numbers, Property Manager phone numbers, Leasing Agent phone numbers, WhatsApp contact and Request Viewing through the approved Viewing Workflow.

## Before purchase

Before payment begins, the customer sees the purchase type, access duration, amount to pay and what the purchase includes.

## Activation

Immediately after successful payment confirmation, the platform activates Verified Access, applies premium permissions, displays confirmation and makes qualifying premium information accessible without manual refresh.

## Security

Verified Access never exposes premium information before successful payment. Contact numbers, WhatsApp, additional photos, viewing requests and protected listing information remain locked under the Customer Access Control Standard.

## Integration

Verified Access integrates with Unlock This Listing, Payment System, House Match, Shop Match, Office Match, Event Hall Match, Customer Access Control Standard, Viewing Workflow, Property Registration and Notifications.

## Founder-approved access validity

Verified Access grants premium access to all eligible properties covered by the purchased package for exactly **72 Hours**, beginning immediately after successful payment. This duration is a permanent platform-wide business rule unless explicitly revised by the Founder.

When the 72-hour period expires, PataSpace automatically removes premium access associated with that Verified Access purchase while preserving purchase history.
