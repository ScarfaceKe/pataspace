# PataSpace Customer Dashboard and Purchased Access Centre

This module extends Master Prompts 1–19. It provides the customer's personal control centre for searches, purchases, viewings, reviews, notifications and account activity.

## Dashboard Home

The dashboard provides quick access to My Profile, My Saved Properties, My Unlocked Properties, My Verified Access, My Viewing Requests, My Reviews, My Notifications, My Payments, My Receipts, My Account Settings and Search History.

## Saved Properties

Customers can save properties before purchasing access. Saved property cards store two cover photos, property summary, current property status, Unlock This Listing option and eligible Verified Access recommendation. Saving a property never unlocks premium information.

## Unlocked Properties

Unlocked records show property or unit identifier, category, unlock date, current availability status, contact information after access and viewing status. If a property later becomes unavailable, the customer keeps purchased access history.

## Verified Access

The dashboard displays active Verified Access entitlements, purchase date, expiry date, remaining time, covered property category and access to eligible properties. If no active entitlement exists, Verified Access is shown as inactive.

## Viewings, Reviews and Notifications

The dashboard links to Viewing History, Reviews and the Notification Centre. Customers can manage their own viewing requests, edit their own reviews and manage their own notifications.

## Payments and Receipts

The dashboard stores payment and receipt records for purchase type, property or unit, amount paid, payment date, payment status, transaction reference, receipt viewing, receipt download preparation and receipt search by date or transaction reference.

## Profile and Search History

Customers can manage profile details and notification settings preparation. Search history is private to the customer and helps them return to previous searches without repeating filters.

## Security

Customers can only access their own dashboard information. They cannot view another customer's purchases, notifications, receipts, viewing requests, saved properties, reviews or search history.

## AI Admin Assistant

The AI Admin Assistant is prepared to monitor dashboard health for missing payment records, failed receipt generation, broken viewing links, notification delivery failures and synchronisation issues without interrupting the customer experience.

## Unlock Access Remaining Time

My Unlocked Properties displays each unlocked property or unit with Property or Unit Identifier, Property Category, Unlock Date, Unlock Expiry Date, Remaining Unlock Time, current property status, contact information after access, and quick access preparation for Call, WhatsApp and Request Viewing.

The remaining unlock time is prepared as a live countdown that can update without requiring the customer to refresh the application. Examples include 2 Days 8 Hours Remaining, 18 Hours Remaining and 45 Minutes Remaining.

When an Unlock This Listing validity period expires, the platform removes premium access for that property or unit, hides protected contact information, hides premium property photos, disables Request Viewing until new Unlock This Listing or active Verified Access exists, and keeps the property visible in My Unlocked Properties as **Unlock Expired** with its unlock history preserved.

## Founder-approved access countdowns

My Unlocked Properties displays Unlock Date, Unlock Expiry Date and live Remaining Unlock Time for every unlocked property. Unlock This Listing is valid for exactly **24 Hours**.

My Verified Access displays Purchase Date, Expiry Date and live Remaining Time for every active Verified Access entitlement. Verified Access is valid for exactly **72 Hours**.

These countdowns are prepared to update automatically without requiring the customer to refresh the application.
