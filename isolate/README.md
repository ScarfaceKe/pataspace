# PataSpace

PataSpace is a Kenya-only smart rental discovery platform for houses, shops, offices, and event halls. This repository starts with the platform foundation required by Master Prompt 1.

## Run locally

```bash
npm install
npm run dev
```

## Foundation guarantees

- Kenya-only scope and location hierarchy.
- Exactly four property categories: Houses, Shops, Offices, Event Halls.
- Role model for Customer, Property Owner, Property Manager, Leasing Agent, and Platform Admin.
- Mobile-first, clean, trust-led product shell.
- Official brand position: Kenya's smart rental discovery platform.
- Four official customer entry cards: 🏠 Find My Home, 🏪 Find My Shop, 🏢 Find My Office, 🎉 Find My Hall.
- Platform-wide design, interaction, performance feedback, trust-through-design, and error-handling standards.
- Structured adaptive guided interviews instead of open-ended AI chat.
