# PataSpace House Match Intelligence and Customer Experience

This module extends the accepted Master Prompts 1–11A. It does not redesign the House Match Engine Foundation.

## Objective

House Match Intelligence ranks, explains, recommends and presents residential results in a simple customer experience while maintaining fairness for Property Owners, Property Managers and Leasing Agents.

## Best Match Ranking

Successful House Match searches are ranked using approved signals: active vacancy confirmation, verification status, freshness of vacancy confirmation, customer preference match quality and previously approved Search Priority rules.

The ranking favours accurate and trustworthy listings.

## Limited Result Batch

Regardless of how many homes match, customers receive only the approved limited batch. The platform avoids overwhelming customers with extremely long result lists.

## Smart Rotation

When many properties satisfy the same search criteria, Smart Rotation prepares different high-quality listings for future searches while respecting Search Priority rules. Customers should not notice the rotation happening.

## Why This Home Matches

Each property card includes simple explanations such as matching the selected location, house type, rent range, nearby facilities and utility preferences.

## AI Summary

Each card includes a clearly labelled **AI Summary**. The summary uses only available listing information and never invents details.

## Property Card Preparation

Every returned residential result prepares property photos, property summary, AI Summary, Why This Home Matches, Unlock This Listing, Verified Access, Request Viewing, Call Property Manager and WhatsApp Property Manager.

## Unlock This Listing and Verified Access

Every property card includes the official residential Unlock pricing key for the residential category. Manual price entry is not used.

When only one or two suitable homes are available, the experience emphasizes Unlock This Listing. When several suitable homes are available within the approved batch, Verified Access is recommended while individual unlock remains available.

## Search Behaviour

The system supports the approved principle that a small number of relevant homes is better than no results when suitable alternatives exist. No duplicate information is requested from registrants.

## Customer Access Control

House Match cards inherit the platform-wide Customer Access Control Standard. Before access, the card may show summary information, AI Summary, Why This Home Matches, Unlock This Listing and Verified Access recommendation only. Contact details, WhatsApp and Request Viewing are unlocked only after Unlock This Listing or Verified Access is purchased.
