# PataSpace Verified Access Intelligence and Access Management

This module extends the accepted Verified Access Foundation without redesigning it.

## Recommendation logic

Verified Access continues to complement Unlock This Listing. If only one or two suitable properties are available, Unlock This Listing is prioritised. If several suitable properties are available in the approved result batch, Verified Access may be recommended while Unlock This Listing remains visible for every individual property.

## Activation

Immediately after successful payment, Verified Access activates, premium permissions are applied, a confirmation can be displayed and premium information becomes available without manual refresh.

## Active access indicator and remaining time

Active customers see **Verified Access Active** and the remaining time, such as 2 Days 15 Hours Remaining, 18 Hours Remaining or 45 Minutes Remaining. Remaining time is derived from the 72-hour expiry timestamp and can be refreshed automatically by the application.

## Premium access

While active, Verified Access unlocks all uploaded property photos, Property Owner phone numbers, Property Manager phone numbers, Leasing Agent phone numbers, call, WhatsApp and Request Viewing through PataSpace for properties in the approved scope.

## Property status management

Verified Access respects the latest property status. If a property becomes occupied, unavailable, Waiting for Verification or temporarily unavailable, the displayed status can update while the customer's purchased Verified Access remains valid until expiry.

## Access recovery and purchase protection

Verified Access is stored against the customer account and scope so access can be recovered after logout, login, device changes, app restart or temporary network interruptions. Customers cannot buy another Verified Access package covering the same search scope while an active entitlement already exists; the platform shows that access is active and displays the remaining time.

## Expiry management

When the 72-hour period expires, premium access is automatically removed, contact information and additional photos are hidden, viewing requests are disabled until new access is purchased and cards return to the public view. No manual action is required.

## Notifications

Prepared notification events are: active immediately after purchase, 24 hours before expiry, 1 hour before expiry and immediately after expiry.

## Security

Verified Access cannot be manually extended, cannot be transferred between customer accounts and never exposes premium information unless an active Verified Access or Unlock This Listing entitlement exists.
